# Free AI API Benchmark Dataset

Performance benchmarks across 7 major free-tier LLM API providers for multi-provider inference routing research.

## What's Inside

This dataset contains inference latency and quality benchmarks for:
- Groq (llama-3.3-70b)
- Cerebras (llama3.1-8b)
- Mistral (mistral-small)
- NVIDIA (llama-3.1-8b)
- OpenRouter (deepseek-chat)
- Gemini (1.5-flash)
- Cloudflare (llama-3.1-8b)

## Use Cases

- **Inference Routing**: Build intelligent multi-provider routers
- **Latency Optimization**: Identify fastest providers per task type
- **Cost Analysis**: Free tier capacity planning
- **Reliability Engineering**: Study failure patterns and rate limits

## Schema

| Field | Type | Description |
|-------|------|-------------|
| id | string | Unique benchmark ID |
| timestamp | ISO 8601 | When benchmark ran |
| provider | string | API provider name |
| model | string | Model used |
| rpm_limit | int | Rate limit (requests/min) |
| task_type | string | Type of inference task |
| latency_ms | float | Response time in milliseconds |
| tokens_input | int | Input token count |
| tokens_output | int | Output token count |
| success | bool | Whether request succeeded |
| rate_limited | bool | Whether hit rate limit |
| free_tier | bool | Whether using free tier |
| cost_usd | float | Cost (always $0 for free tier) |
